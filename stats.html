01

Statistik publik

Tayangan, suka, komentar, bagikan, dan simpan dibaca lewat TikWM, API pihak ketiga. Angkanya bisa berubah kapan saja.

02

Metadata dari file

Resolusi, FPS, codec, audio, dan HDR dibaca dari sebagian kecil file video — bukan dari tebakan atau label unggahan.

03

File tidak diunggah

URL dikirim ke TikWM. File video diambil langsung dari CDN TikTok untuk dibaca di browser, tidak pernah melewati server KoRifCan.
